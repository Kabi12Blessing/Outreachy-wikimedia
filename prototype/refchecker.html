Wikipedia Duplicate Reference Detector

This is a small prototype built to demonstrate one of the core ideas behind Lusophone Wishlist Wish 3, detecting when a Wikipedia editor is about to add a reference that already exists in the article. Built by EileenBlessing · Outreachy Round 32.
